# 2. ¿Qué es La Goleada?

La Goleada es una quiniela de fútbol para una comunidad de amigos.

Cada participante pronostica el marcador de los partidos.

Ejemplo:


Olimpia 2
Motagua 1

El sistema compara el pronóstico con el resultado oficial y asigna puntos.

3. Reglas principales
3.1 Pronóstico exacto

Cuando el marcador pronosticado coincide completamente con el resultado oficial.

Ejemplo:

Pronóstico: 2-1
Resultado: 2-1

Puntos:

3
3.2 Pronóstico parcial

Cuando no se acierta el marcador exacto, pero sí el resultado general.

Ejemplo:

Pronóstico: 1-0
Resultado: 3-2

Ambos indican victoria del equipo local.

Puntos:

1
3.3 Pronóstico incorrecto

Cuando no se acierta el marcador ni el resultado general.

Ejemplo:

Pronóstico: 2-0
Resultado: 0-1

Puntos:

0
3.4 Partido doble

Cada jornada tiene un partido con puntuación doble.

En ese partido:

Exacto: 6 puntos
Parcial: 2 puntos
Incorrecto: 0 puntos

El partido doble estará identificado visualmente.

3.5 Sin pronóstico

Si no se envía un pronóstico antes del cierre:

0 puntos
4. Cierre de pronósticos

Cada partido cierra:

5 minutos antes de la hora de inicio

Ejemplo:

Inicio del partido: 7:00 p. m.
Cierre del pronóstico: 6:55 p. m.

El horario válido es el del servidor.

La hora del teléfono o computadora no modifica el cierre.

4.1 Regla exacta

El pronóstico puede guardarse mientras:

hora actual < hora de cierre

Exactamente en la hora de cierre ya no se podrá guardar.

4.2 Recomendación

No espere hasta el último segundo.

Envíe sus pronósticos con anticipación para evitar problemas de:

Internet.
Batería.
Navegador.
Retrasos de red.
Cierre del partido.
5. Privacidad de pronósticos
5.1 Antes del cierre

Solo usted puede ver su pronóstico.

No podrá ver los pronósticos de otros participantes.

Los administradores tampoco deben tener ventaja para verlos antes del cierre.

5.2 Después del cierre

Cuando el partido cierre:

Todos podrán ver los pronósticos enviados.
Nadie podrá modificarlos.
Los puntos permanecerán ocultos hasta el procesamiento.
5.3 Después del procesamiento

Cuando el administrador procese el resultado podrá ver:

Pronóstico.
Tipo de acierto.
Puntos obtenidos.
Resultado oficial.
6. Registro
6.1 Abrir registro

En la página inicial seleccione:

Crear cuenta
6.2 Datos requeridos

Ingrese:

Nombre.
Apellido.
Nickname.
Correo.
Contraseña.
Confirmación de contraseña.
Equipo favorito.

También deberá aceptar las reglas.

6.3 Nickname

El nickname es el nombre que verán los demás participantes.

Ejemplos:

Juancho
ElProfe
CatrachoFC

Debe ser único.

No podrá utilizar un nickname ya registrado, aunque cambien las mayúsculas.

Ejemplo:

Juancho
JUANCHO

Se consideran equivalentes.

6.4 Correo

El correo se utilizará para:

Confirmar la cuenta.
Iniciar sesión.
Recuperar la contraseña.
Recibir avisos importantes.

El correo no podrá cambiarse posteriormente.

Revíselo cuidadosamente antes de registrarse.

6.5 Contraseña

Utilice una contraseña:

Larga.
Difícil de adivinar.
Diferente a otras cuentas.
Que no comparta con nadie.

Se recomienda una frase de contraseña.

Ejemplo conceptual:

MiEquipoGanaEsteDomingo2026

No use ese ejemplo literalmente.

7. Confirmación de correo

Después del registro recibirá un correo.

7.1 Procedimiento
Abra el correo.
Seleccione el enlace de confirmación.
Espere el mensaje de cuenta confirmada.

Después de confirmar, la cuenta quedará:

Pendiente de aprobación
7.2 No recibí el correo

Revise:

Bandeja principal.
Spam.
Promociones.
Correo ingresado.
Espacio disponible en su cuenta.

Luego seleccione:

Reenviar confirmación

No presione repetidamente.

7.3 Enlace expirado

Si el enlace expiró:

Abra la página de acceso.
Seleccione Reenviar confirmación.
Ingrese su correo.
Use el nuevo enlace.
8. Aprobación administrativa

Después de confirmar su correo, un administrador deberá aprobar la cuenta.

Durante este periodo verá:

Tu cuenta está pendiente de aprobación

No podrá participar hasta ser aprobado.

La aprobación no es automática porque la quiniela está destinada a una comunidad específica.

9. Iniciar sesión
9.1 Procedimiento
Seleccione Iniciar sesión.
Ingrese su correo.
Ingrese su contraseña.
Seleccione Ingresar.
9.2 Estados que pueden impedir el acceso
Correo no confirmado.
Cuenta pendiente.
Cuenta rechazada.
Cuenta bloqueada.
Cuenta desactivada.
Contraseña incorrecta.
9.3 Recordar sesión

Si aparece la opción:

Recordarme

Úsela solo en dispositivos personales.

No la active en equipos compartidos.

10. Recuperar contraseña
10.1 Solicitar recuperación
Seleccione Olvidé mi contraseña.
Ingrese su correo.
Seleccione Enviar instrucciones.

Por seguridad, el sistema mostrará un mensaje general aunque el correo no exista.

10.2 Restablecer
Abra el correo.
Seleccione el enlace.
Ingrese una nueva contraseña.
Confirme.
Inicie sesión nuevamente.

El enlace:

Tiene vencimiento.
Solo puede usarse una vez.
Deja de funcionar después del cambio.

Puede incluir:

12.1 Abrir la sección

Pronósticos
12.2 Ingresar marcador

En cada partido verá:

Equipo local.

Fecha.

12.3 Guardado

Según el diseño final, el sistema podrá:

Guardar automáticamente.
Mostrar un botón Guardar.
Utilizar ambas opciones.

Estados posibles:

Guardando...
Guardado
Error al guardar
Cerrado
12.4 Confirmar persistencia

Después de guardar:

Espere el mensaje Guardado.
Actualice la página si desea verificar.
Confirme que el marcador continúa visible.
12.5 Marcador 0-0

Un pronóstico:

0-0

es válido.

No significa que no se haya enviado pronóstico.

12.6 Valores no permitidos

No puede utilizar:

Números negativos.
Decimales.
Texto.
Campos incompletos.
Marcadores mayores al máximo configurado.
13. Editar un pronóstico

Mientras el partido esté abierto:

Abra el partido.
Cambie el marcador.
Guarde.
Confirme el estado Guardado.

Puede editarlo varias veces antes del cierre.

Solo contará la última versión guardada correctamente.

14. Pronóstico cerrado

Cuando el partido cierre:

Los campos estarán bloqueados.
No podrá guardar cambios.
Verá un estado como Cerrado.
Podrá ver pronósticos ajenos cuando la regla lo permita.

No solicite al administrador que cambie su pronóstico después del cierre.

15. Estados de partido
15.1 Programado

El partido tiene fecha y todavía no inicia.

15.2 Reprogramado

La fecha o la hora cambiaron.

Revise la nueva hora y el nuevo cierre.

15.3 Cerrado

Ya no se aceptan cambios.

15.4 Suspendido

El partido fue detenido o aplazado sin resolución final.

Los pronósticos se conservan.

15.5 Reanudado

El partido suspendido tiene nueva continuidad o programación.

15.6 Finalizado pendiente

El partido terminó, pero el resultado todavía no fue procesado.

15.7 Procesado

El resultado y los puntos ya fueron calculados.

15.8 Cancelado

El partido no otorgará puntos.

16. Reprogramaciones
16.1 Qué ocurre con su pronóstico

Cuando un partido se reprograma:

Su pronóstico se conserva.
La nueva fecha se muestra.
El cierre puede cambiar.
El administrador puede reabrir la edición.
16.2 Si se reabre

Podrá modificar el pronóstico hasta el nuevo cierre.

16.3 Si no se reabre

El pronóstico seguirá bloqueado aunque el partido tenga nueva fecha.

La interfaz deberá mostrarlo claramente.

16.4 Orden de jornadas

Un partido de Jornada 5 puede jugarse después de Jornada 10.

Esto es válido.

Los partidos se ordenan principalmente por su fecha real, no por el número de jornada.

17. Partido suspendido

Si un partido se suspende:

No se asignarán puntos todavía.
Su pronóstico se conservará.
Deberá esperar la decisión administrativa.
Puede reanudarse, reprogramarse o cancelarse.
18. Partido cancelado

Si el partido se cancela:

No obtiene puntos.
Tampoco se considera pronóstico incorrecto.
El partido permanecerá visible como cancelado.
El historial se conserva.

Después del cierre podrá abrir el detalle del partido.

22.1 Orden

La clasificación se ordena por:

Puntos.
Exactos.

22.3 Orden visual entre empatados

Los usuarios empatados podrán mostrarse alfabéticamente.

Eso no cambia que compartan posición.

23. Exactos y parciales
Exactos

Cantidad total de marcadores completamente acertados.

Parciales

Cantidad total de resultados generales acertados sin marcador exacto.

Puntos

Suma total de puntos obtenidos.

Los partidos dobles afectan los puntos, pero cada acierto sigue contando como un exacto o parcial.

24. Usuario aprobado después de iniciar la temporada

Si es aprobado después de varias jornadas:

Comenzará con cero puntos.
No recibirá puntos retroactivos.
Podrá pronosticar partidos todavía abiertos.
Aparecerá en la clasificación activa.
25. Historial de temporadas

En la sección de historial podrá consultar:

Temporadas anteriores.
Tabla final.
Campeón o campeones.
Posiciones.
Puntos.
Exactos.
Parciales.

Las temporadas anteriores no se eliminan.

26. Campeones compartidos

Si dos o más participantes comparten la primera posición, todos serán considerados campeones.

No existe un desempate adicional basado en parciales.

27. Notificaciones

El sistema podrá mostrar notificaciones internas sobre:

Cuenta aprobada.

Partido cancelado.
Pronóstico próximo a cerrar.
Resultado procesado.
Avisos administrativos.
27.1 Marcar como leída

Puede:

Abrir la notificación.
Marcarla individualmente.
Marcar todas como leídas.
27.2 Correo

Algunas notificaciones podrán enviarse por correo.

Los recordatorios por correo dependerán de la disponibilidad gratuita del sistema.

Las notificaciones internas son la fuente principal.

28.2 Equipo favorito

Cambiar el equipo favorito no modifica:

Historial.
28.3 Avatar

No se utilizan avatares personales.

Se mostrará el logo del equipo favorito.

La aplicación estará diseñada para dispositivos móviles.

Recomendaciones:

Use un navegador actualizado.
Mantenga conexión estable.
Verifique el estado Guardado.
No cierre inmediatamente después de modificar.
Actualice la página si algo no parece correcto.
33. Uso en computadora

Puede utilizar:

Chrome.
Edge.
Firefox.
Safari compatible.

Se recomienda mantener el navegador actualizado.

34. Contador de cierre

La interfaz podrá mostrar:

Cierra en 00:12:43

El contador es informativo.

La validación final la realiza el servidor.

Puede existir una diferencia mínima por latencia o actualización de pantalla.

35. Guardado cerca del cierre

Un pronóstico puede parecer enviado antes del cierre, pero llegar al servidor después.

En ese caso será rechazado.

Por eso debe guardar con anticipación.

36. Mensajes comunes
Guardado

El pronóstico se almacenó correctamente.

Guardando

La solicitud todavía está en proceso.

No cierre la página todavía.

Error al guardar

El pronóstico no fue almacenado.

Revise conexión y vuelva a intentar si el partido continúa abierto.

Partido cerrado

Ya no se aceptan cambios.

Cuenta pendiente

El correo fue confirmado, pero falta aprobación.

Sesión expirada

Debe iniciar sesión nuevamente.

37. Problemas comunes
No puedo registrarme

Revise:

Todos los campos.
Correo válido.
Contraseñas iguales.
Nickname disponible.
Equipo seleccionado.
Reglas aceptadas.
Mi nickname ya existe

Elija otro.

Las mayúsculas no crean un nickname distinto.

No recibí confirmación

Revise spam y utilice Reenviar confirmación.

Confirmé el correo, pero no puedo entrar

La cuenta probablemente está pendiente de aprobación.

No puedo guardar pronóstico

Revise:

Partido abierto.
Valores válidos.
Sesión activa.
Conexión.
Estado de mantenimiento.
Mi pronóstico desapareció
Actualice la página.
Abra nuevamente el partido.
Revise si mostró Guardado.
Informe al administrador con partido y hora.
No veo pronósticos de otros

Antes del cierre es correcto.

No veo mis puntos

Los puntos aparecen después del procesamiento.

La jornada está fuera de orden

Los partidos se ordenan por fecha real.

Un partido de jornada anterior puede jugarse después.

La tabla parece incorrecta

Espere a que todos los resultados correspondientes sean procesados.

Si continúa, informe al administrador.

40. Conducta esperada

La quiniela funciona sobre confianza y reglas comunes.

No se permite:

Intentar ver pronósticos antes del cierre.
Compartir cuentas.
Solicitar cambios tardíos.
Intentar manipular resultados.
Utilizar herramientas técnicas para evadir controles.
Suplantar a otro participante.
Abusar de errores del sistema.
41. Administradores como participantes

Los administradores pueden participar en la quiniela.

Sin embargo:

Deben pronosticar antes del cierre.
No pueden ver pronósticos abiertos.
No pueden modificar sus puntos.
No pueden editar pronósticos cerrados.
No tienen ventajas deportivas.
42. Privacidad

Otros usuarios podrán ver principalmente:

Nickname.
Equipo favorito.
Posición.
Pronósticos después del cierre.
Puntos.
Exactos.
Parciales.

No podrán ver:

Correo.
Contraseña.
Nombre completo, salvo que se defina lo contrario.
Sesiones.
Datos técnicos.
43. Modo mantenimiento

Cuando el sistema esté en mantenimiento verá un mensaje informativo.

Durante ese periodo:

Puede no ser posible iniciar sesión.
No podrá guardar pronósticos.
Algunas páginas estarán temporalmente cerradas.

Revise la hora anunciada y vuelva a intentar después.

44. Si el sistema falla antes del cierre

Si no puede acceder:

Tome una captura con hora visible.
No comparta su contraseña.
Informe inmediatamente al administrador.
Indique partido y pronóstico que intentaba guardar.

La evidencia no garantiza que se acepte un pronóstico manual.

Cualquier excepción deberá aplicar una política igual para todos.

45. Política sobre cambios manuales

Como regla general:

No se aceptan pronósticos por chat.
No se aceptan pronósticos por llamada.
No se aceptan cambios después del cierre.
No se modifican puntos manualmente.

Esto protege la igualdad entre participantes.

No.

Sí, si comparten la primera posición.

No.

¿Puedo participar si me aprueban tarde?

Sí, pero comienza con cero puntos.

Regístrese y confirme su correo.

Envíe sus pronósticos antes del cierre.
Revise que hayan sido guardados.
